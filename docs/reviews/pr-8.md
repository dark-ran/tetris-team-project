# PR #8 리뷰 반영

- Esc로 게임 위에 메뉴를 연다. 게임 화면을 캡처해 흐릿하고 어둡게 표시한다.
- 메뉴는 게임 복귀·설정·시작 메뉴 이동·프로그램 종료를 제공하며, 열린 동안 조작 키를 게임에 전달하지 않는다.
- 설정에서 화면 크기·조작 키·구분 문자 모드를 편집하고, 저장 실패 시 편집값과 오류 안내를 유지한다.
- 종료 화면에 Space 재시작 안내와 키 연결을 제공한다. 이름 입력란의 공백은 재시작으로 처리하지 않는다.
- 미리보기 종료 버튼을 제거하고, 상태 표시·기록 등록/저장 재시도·신규 기록 강조를 연결했다.
- 셀 위치·종류별 색상·메뉴 배경·키 차단·저장 실패를 테스트한다.

`./gradlew build jacocoTestReport`로 개별 브랜치를 검증했다.
실제 저장·입력·타이머는 PR #7, 실제 엔진 상태 전환은 PR #11과 함께 연결한다.
겹치는 GameScreen/SettingsScreen/GameOverScreen/ScoreboardScreen은 이 브랜치의 구현을 유지하고,
AppController/AppState는 PR #11의 구현을 유지한다.
