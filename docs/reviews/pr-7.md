# PR #7 리뷰 반영

- Esc는 게임 메뉴 호출 전용이다. 사용자 설정에서 변경할 수 없으며, P 일시정지 키는 기본 조작에서 제외했다.
- 일부 조작 키 설정은 기본값으로 보완한 후 중복·예약 키·누락 값·자동 행동을 검증한다.
- 파일에서 읽은 설정도 같은 검증을 거친다. 잘못된 설정은 기본값으로 복구하고 이전 P 설정은 제외한다.
- 저장은 임시 파일의 원자적 교체로 처리한다. 실패는 호출자에게 전달하고 기존 파일·현재 설정·변경 알림을 유지한다.
- KeyMapper·InputHandler·Swing 타이머를 구현했다. 실제 메뉴 표시와 상태 전환은 PR #8·#11에서 연결한다.

검증: Java 21 / macOS에서 `./gradlew build jacocoTestReport` 성공. 64개 테스트 통과.
설정 실패·부분 설정의 재로드·예약 키·중복 키·반복 입력·실제 타이머 정지와 재개를 포함한다.
