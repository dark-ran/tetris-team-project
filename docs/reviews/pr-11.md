# PR #11 리뷰 반영

- GAME_MENU 상태에서 엔진과 타이머를 멈추고 보드·현재 블록·점수·다음 블록을 유지한다.
- 게임 메뉴에서 설정으로 이동했다가 돌아오면 메뉴를 유지한다. 게임 복귀를 선택해야 재개한다.
- 설정 저장 후 기존 게임을 초기화하지 않고 입력·화면·창 크기에 변경 내용을 적용한다.
- 게임 종료 화면의 Space는 기존 새 게임 처리와 연결되어 점수·레벨·속도·생성/삭제 수를 초기화한다.
- 실제 플레이 화면의 미리보기 종료 버튼을 제거했다. 자연스러운 게임오버의 점수/랭킹 처리는 유지한다.
- 이름 등록 저장 실패는 화면에 전달하고 기존 대기 기록을 유지한다.

개별 검증: `./gradlew build jacocoTestReport`.
엔진 유지·설정 실패·재개·기존 랭킹 저장/재시도 경로를 검사한다.

이 브랜치의 설정 및 UI API 연결 계약에는 다른 담당 브랜치의 구현이 필요하다.
GameSettings/InputHandler/KeyMapper/GameLoop는 PR #7 구현을, UI는 PR #8 구현을 사용한다.
AppController/AppState와 앱 테스트는 이 브랜치를 유지한다.

세 브랜치를 합친 후에는 다음 검사도 수행한다.

```sh
./gradlew reviewIntegrationTest
./gradlew reviewWindowTest
```

첫 검사는 실제 설정 저장·입력·타이머·화면을 연결한다.
둘째 검사는 실제 창과 키보드 포커스, 이름 입력 중 공백, 게임오버 Space 재시작, 창 닫기를 검사한다.
저장 검사에는 임시 사용자 경로를 사용한다.
