# 줄 삭제 아이템

기준: TeamProject_Req2.pdf 7–8쪽.

- 아이템 모드에서 누적 삭제 줄 수가 10, 20, 30줄에 도달하거나 그 기준을 넘을 때마다 아이템을 한 개 확정 지급한다.
- 지급 시 새로 추가되는 다음 블록에 아이템이 포함된다. 이미 미리 본 블록은 바뀌지 않는다.
- 현재 구현한 아이템은 줄 삭제 아이템 한 종류이며, 일반 모드에서는 등장하지 않는다.
- 일반 블록의 네 칸 중 한 칸을 각각 25% 확률로 선택하여 문자 `L`을 표시한다. L자 블록만 대상으로 제한하지 않는다.
- 이동과 회전 중에도 L은 같은 칸에 붙어 있다. 보드와 다음 블록 미리보기 모두 L을 표시한다.
- 블록 고정 시 L이 있는 줄을 빈칸이 있어도 삭제한다. 동시에 꽉 찬 다른 줄도 삭제한다.
- 같은 줄은 한 번만 삭제하고, 삭제한 줄의 점수와 낙하 점수는 기존 규칙으로 계산한다.
- 아이템으로 삭제한 줄도 누적 삭제 줄 수에 포함한다. 새 게임에서는 누적 수치와 지급 대기를 초기화한다.
- 아이템 모드 화면에 누적 삭제 줄 수와 다음 아이템까지 필요한 줄 수를 표시한다.

블록 모양(`PieceType`)과 아이템 종류(`ItemType`)를 분리하였다. 생성기는 아이템 위치를 정하고,
`PieceRules`는 종류에 맞는 이동 규칙과 고정 효과를 연결한다. 줄 삭제 효과는 `LineClearEffect`에서 처리한다.

검증: `./gradlew build jacocoTestReport`. 아이템 위치·회전, 줄 삭제 중복 방지, 10줄 지급 시점,
미리보기와 실제 블록의 일치, 점수 반영, 색각 모드별 L 표시를 검사한다.
부착 위치는 일곱 블록 각각 100,000회 생성하여, 각 위치의 기대 횟수 25,000회 대비 오차가 ±5% 이내인지 검사한다.
