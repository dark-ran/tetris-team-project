# 점수 기록

- 일반 모드와 아이템 모드는 각각 상위 10개 기록을 유지한다.
- 각 기록에 이름, 점수, 게임 모드, 플레이한 난이도(EASY·NORMAL·HARD)를 저장한다.
- 스코어보드의 난이도 열에서 점수를 얻은 난이도를 확인할 수 있다.
- 게임 중 설정을 바꾸더라도 현재 게임의 난이도는 유지하며, 점수에도 현재 게임의 난이도를 기록한다.
- 저장에 실패하면 이름·점수·모드·난이도를 보존하여 같은 기록으로 다시 저장한다.
- 같은 이름과 점수가 있어도 난이도가 다른 기록을 잘못 강조하지 않는다.

## 파일 형식

사용자별 저장 경로의 UTF-8 TSV 파일을 사용한다.
첫 줄은 `TETRIS-SCORES-3`이며, 이후 각 줄에 이름·점수·모드·난이도를 탭으로 구분한다.
저장은 임시 파일을 만든 뒤 원자적으로 교체한다.

이름·점수만 있는 1판 파일과 모드까지 있는 2판 파일도 읽는다.
난이도가 없던 기록은 NORMAL로 처리하고, 다음 저장에서 3판 형식으로 옮긴다.
1판 파일의 모드는 일반 모드로 처리한다. 올바른 기존 기록은 유지하며, 손상된 행만 건너뛰고 경고를 표시한다.

## 검증

- 모든 난이도와 두 게임 모드의 저장·불러오기
- 두 가지 기존 파일 형식의 변환과 기존 기록 보존
- 손상된 난이도 값 처리
- 게임 도중 설정 변경 및 저장 재시도 시 플레이한 난이도 유지
- 난이도 표시와 새 기록 강조
