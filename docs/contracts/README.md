# 모듈 연결 안내

게임의 현재 구조는 [구조 설명](../architecture.md), 사용자 동작과 수치는 [게임 안내](../game-guide.md), 통합 상태는 [검증 결과](../verification.md)를 기준으로 확인한다. AppController·입력·게임 루프·화면 연결은 main에 반영되어 있다.

| 연결할 내용 | 문서 |
|---|---|
| 게임 시작·행동 결과·상태 사본·시작 위치 | [게임 엔진](game-engine.md) |
| 보드 좌표·칸 값·모양·회전 | [보드와 블록](board-and-piece.md) |
| L의 부착·회전·지정 행 삭제 | [줄 삭제 아이템](line-clear-item.md) |
| W의 아래 칸 삭제·접촉 후 이동 제한 | [무게추](weight-item.md) |
| B의 충돌·효과 중심·5×5 삭제 | [폭탄](bomb-item.md) |
| G의 고정 속성·줄 삭제 배율 | [황금 블록](golden-item.md) |
| 1칸 보상·자동 낙하·일반 점수 | [1칸 블록](single-item.md) |
| 모드·난이도·구형 파일 호환·새 기록 | [점수 기록](scoreboard.md) |

기본 칸 값과 아이템 속성은 별도로 관리한다. 화면은 GameState의 사본을 읽고 엔진의 행동 메서드를 통해 변경한다. 새 아이템은 이동·고정 효과·점수 허용·보드 잔류 규칙을 조합하고 미리보기와 실제 생성에 동일한 Tetromino 정보를 전달한다.

기능 연결 규칙을 바꾸면 호출하는 코드, 회귀 테스트, 명세를 함께 갱신한다. 과거 작업별 수치와 상태는 [개발 기록](../work-items/README.md)에 보관한다.
