# 1칸 블록

- 아이템 모드에서 10줄을 삭제할 때마다 지급하는 아이템에 포함한다.
- L·무게추 W·폭탄 B·황금 G·1칸 블록 1을 각각 20% 확률로 선택한다.
- 한 칸짜리 모양과 문자 `1`로 표시한다. 색각 모드와 무늬 설정에 관계없이 표시한다.
- 새로 추가되는 미리보기에 나타난 뒤 같은 블록이 실제로 생성된다. 기존 미리보기는 바꾸지 않는다.
- 기존 자동 낙하, 좌우·아래 이동, 즉시 낙하를 사용한다. 회전해도 모양은 같다.
- 바닥이나 다른 블록을 만나면 일반 블록과 같은 규칙으로 고정된다.
- 일반 낙하·줄 삭제 점수를 적용하며, 완성한 줄은 누적 삭제 줄 수에 포함한다.
- 일반 모드의 블록 생성 목록에는 추가하지 않는다. 새 게임에서는 이전 보상과 미리보기를 초기화한다.

## 연결과 검증

`ItemGenerator`의 보상 목록에 한 칸 블록 생성기를 등록한다.
`PieceRules`에서는 기존 이동·줄 삭제·점수 규칙을 재사용하며, 엔진에 별도 분기를 추가하지 않는다.
10줄 보상부터 미리보기·실제 생성·낙하·고정·점수·재시작까지 연결한 테스트를 수행한다.
전체 아이템 100,000회 생성에서 종류별 기대 횟수 대비 상대오차 5% 이내인지 확인한다.
