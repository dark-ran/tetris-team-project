# 무게추 아이템

기준: TeamProject_Req2.pdf 7·9쪽.

## 등장과 표시

- 아이템 모드에서 누적 10줄 삭제마다 다음 목록에 아이템 한 개를 추가한다.
- 지급할 아이템은 L·W·[폭탄 B](bomb-item.md)·[황금 G](golden-item.md)·[1칸 블록 1](single-item.md) 중 각각 20% 확률로 선택한다. L의 부착 위치는 네 칸 각각 25%이다.
- 이미 미리 본 블록은 바꾸지 않는다. W가 미리보기에 표시되면 그 W가 다음에 생성된다.
- 무게추는 아래 모양을 사용하며, 보드와 미리보기의 여섯 칸 모두에 W를 표시한다.

```text
 WW
WWWW
```

## 이동·삭제·점수

- 폭은 4칸이며 회전하지 않는다. 다른 블록에 닿기 전까지 좌우 이동할 수 있다.
- 고정 블록이나 바닥에 처음 닿으면 그 무게추의 좌우 이동을 계속 제한한다.
- 낙하하면서 자신의 경로에 겹치는 고정 칸을 삭제한다. 아래 블록을 만났다고 고정되지 않는다.
- 경로 밖의 블록과 위쪽 블록은 원래 위치를 유지한다. 줄을 내리는 효과는 없다.
- 즉시 낙하도 같은 경로의 블록을 삭제한다. 착지 예상 위치를 조회하는 것만으로는 삭제하지 않는다.
- 바닥에 도달한 뒤 다음 낙하 처리 시 사라지고 다음 블록을 생성한다. 즉시 낙하는 한 번에 마친다.
- 무게추는 고정 칸으로 남지 않는다. 낙하·블록 삭제 점수는 모두 0점이다.
- 지운 개별 칸은 삭제한 줄 수나 다음 아이템 지급 조건에 포함하지 않는다.

회전 제한, 바닥 도달 후 소멸, 종류별 20% 비율은 팀에서 정한 동작 규칙이다.

## 연결과 검증

`ItemGenerator`에서 지급할 종류를 선택한다. 새 아이템의 생성기는 이 목록에 추가한다.
`PieceRules`에서 이동·고정 효과, 점수 지급 여부, 고정 칸을 남길지 여부를 연결한다.
`CrushingMovement`는 경계 안에서 낙하하며 겹치는 칸을 지운다. 최초 접촉 상태는 엔진이 유지한다.
화면은 아이템의 문자와 실제 칸 목록을 사용한다. 일반 블록의 일곱 종류와 선택 확률은 유지한다.

`./gradlew build jacocoTestReport`로 다음 내용을 검사한다.

- 10줄 지급, 미리보기와 실제 생성의 일치, 재시작 초기화
- 자동 낙하·아래 키·즉시 낙하의 경로 삭제, 최초 접촉 후 좌우 제한 유지
- 경로 밖 블록 보존, 무게추 소멸, 점수·누적 삭제 줄 수 제외
- 색각 모드 5종의 보드·미리보기 W 표시
- 아이템 100,000회 생성 시 L·W·B·G 각각 기대 횟수 25,000회 대비 오차 ±5% 이내
