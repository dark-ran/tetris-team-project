# 중간평가 확인 현황

2026-10-27 기준으로 기본 게임과 Req2 아이템 확장 기능을 main에 반영했다.

| 항목 | 상태 |
|---|---|
| 기본 게임·메뉴·설정·점수 저장 | 구현·검사 완료 |
| 난이도·생성 가중치·속도·기록 | 구현·검사 완료 |
| L·무게추·폭탄·황금·1칸 아이템 | 보상·미리보기·생성·효과 연결 완료 |
| 줄 삭제 연출 | 재시작·화면 이탈·G 표시 보완 완료 |
| 전체 검사 | 단위 541 · 통합 1 · 실제 창 9 · 성능 6 통과 |
| 전체 줄 커버리지 | 93.50% |
| macOS arm64 | 앱 생성·실행·설정과 점수 유지 확인 |
| Windows x64 | 자동 검사·패키지 생성 완료, 실제 PC 확인 필요 |

평가 준비의 남은 현장 작업은 패키지를 평가 PC에 미리 내려받아 첫 실행을 확인하고, Windows 사용 팀원의 실행 결과를 대표 이슈에 남기는 것이다. 최소 사양 PC와 다른 Mac 최초 실행까지 확인한 것으로 확대하지 않는다.
