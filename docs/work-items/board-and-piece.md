## 목적과 범위

엔진이 사용할 보드 검사·고정·줄 삭제, 블록 종류·모양·회전과 다음 목록을 제공한다.
보드는 블록 종류에 대응하는 값만 저장하고, 실제 색상과 무늬는 화면에서 결정한다.

대상은 `Board`, `PieceType`, `Tetromino`, `PieceQueue`이다.
좌표와 복사 방식, 실패 처리, 사용 예시는 연결 문서를 따른다.

## 요구사항과 검증

절 번호는 [요구사항 문서](../requirements.md)를 기준으로 한다.

| 근거 | 검증할 동작 | 테스트 |
|---|---|---|
| 3절 · 보드 | 20행 10열, 초기화, 고정된 칸 조회 | `BoardTest` |
| 3절 · 일곱 블록 | 종류별 저장값과 초기 모양 | `PieceTypeTest`, `TetrominoTest` |
| 3절 · 무작위 선택과 다음 블록 | 일곱 선택 값 대응, 중복 선택, 미리보기 순서 | `PieceQueueTest` |
| 4절 · 회전 | 네 방향 모양, 네 번 회전 후 복원 | `TetrominoTest` |
| 4절 · 충돌 | 경계·기존 블록·빈 부분 검사, 잘못된 고정의 원본 유지 | `BoardTest` |
| 3절 · 줄 삭제 | 한 줄·여러 줄·분리된 줄 삭제, 순서와 저장값 유지 | `BoardTest` |
| 12절 · 상태 보호 | 배열·목록·보드 사본 수정이 원본에 영향 없음 | 네 테스트 클래스 |

상태 보호는 데이터 무결성 검증이다. 성능과 실제 운영체제별 플레이는 통합 검증에서 확인한다.
