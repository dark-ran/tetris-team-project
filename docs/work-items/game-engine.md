## 목적과 범위

게임 행동을 처리하고, 전체 상태와 행동별 결과를 다른 모듈에 제공한다.
이동·회전·낙하·고정·줄 삭제·생성·일시정지·게임오버가 대상이다.
점수 계산, 낙하 시간 관리, 랭킹과 화면 표시는 각 연결 모듈에서 담당한다.

대상은 `GameEngine`, `GameAction`, `GamePhase`, `GameState`, `GameActionResult`와
시작 위치 규칙 `PieceSpawnPolicy`, `CenteredPieceSpawnPolicy`이다.

## 완료 기준과 검증

절 번호는 [요구사항 문서](../requirements.md)의 3·4·8·12절을 기준으로 한다.
식별자는 기능 변경과 테스트를 연결할 때 사용한다.

| 식별자 | 완료 기준 | 검증 |
|---|---|---|
| 게임행동-01 | 새 게임과 다음 목록 | 일곱 종류 생성, 기본 시작 위치, 재시작 초기화 |
| 게임행동-02 | 좌우 이동과 충돌 | 양쪽 경계와 고정된 블록 |
| 게임행동-03 | 회전과 거부 | 네 번 복원, O 유지, 벽·바닥·기존 블록 |
| 게임행동-04 | 자동·수동 하강과 즉시 낙하 | 실제 이동 거리, 바닥 고정, 다음 생성 |
| 게임행동-05 | 줄 삭제 결과 | 한 줄·네 줄 삭제와 누적 수치 |
| 게임행동-06 | 일시정지와 재개 | 조작 차단, 상태 유지, 재개 후 낙하 |
| 게임행동-07 | 게임오버 전환 | 생성 실패, 이후 조작 차단, 마지막 점수 자료 유지 |
| 게임행동-08 | 점수·레벨 반영 | 값 검증, 두 값 유지, 최종 점수 반영 |
| 게임행동-09 | 상태 데이터 무결성 | 사본 수정과 이후 행동이 이전 사본에 영향 없음 |
| 게임행동-10 | 생성 규칙 확장 | 다른 시작 위치와 생성 실패 규칙 |

데이터 무결성은 상태 보호 검증이다. 성능과 운영체제별 플레이는 통합 검증에서 확인한다.

## 연결 상태

- [x] 행동 처리와 상태 사본을 제공한다.
- [x] 점수·레벨 반영과 누적 수치 조회를 제공한다.
- [x] 생성 위치와 목록 설정을 객체로 전달할 수 있다.
- [x] 임시 화면의 블록 상태와 직접 조작 입력을 제거했다.
- [x] 유닛 테스트와 커버리지 기준을 통과했다.
- [ ] 코드와 연결 규칙 검토를 완료했다.
- [ ] 입력·루프·앱 제어·화면을 연결하고 통합 검증을 완료했다.

## 후속 작업

| 담당 범위 | 구현·연결할 내용 | 확인할 결과 |
|---|---|---|
| 2번 · 입력·루프 | 키 변환, 자동 낙하, 정지·재개·간격 변경 | 앱 제어에 행동 전달, 일시정지 중 자동 낙하 중단 |
| 3번 · 앱 제어 | 새 게임, 점수·레벨·속도, 루프 제어, 게임오버 후처리 | 최종 점수 반영 뒤 랭킹 처리, 후처리 중복 없음 |
| 4번 · 화면 | 보드·블록·위치·다음 목록·점수·상태 표시 | 실제 상태 그리기, 화면 키를 입력 계층에 전달 |

통합 검증에는 새 게임, 연속 입력, 자동 낙하, 일시정지·재개, 게임오버·랭킹·재시작을 포함한다.
